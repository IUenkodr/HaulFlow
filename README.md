# 🚛 HaulFlow: Field Operations Command Center
**Developed for TEAM YOCAM**

HaulFlow is a high-fidelity, production-ready Android application designed for trucking service operations. It bridges the gap between financial management and real-time asset tracking.

## 🚀 Core Modules
- **Cash Flow Manager**: High-precision financial ledger with local-first storage and PDF/CSV exports.
- **Fleet Tracking System**: Real-time location monitoring via Foreground Services and Google Maps.
- **Command Center Dashboard**: Unified operational awareness for fleet managers.

## 🛠 Tech Stack
- **Language**: Kotlin
- **UI**: Jetpack Compose
- **Architecture**: MVVM + Clean Architecture
- **Database**: Room (Local) & Firebase Firestore (Cloud Sync)
- **DI**: Hilt
- **API**: Retrofit + OkHttp
